# 本机快捷添加与节点入口优先级设计

用户批准：两项一起改，先打macOS包，确认体验后再打其他平台。2026-11-16。

一个节点可保存1–8条入口，自上而下优先LAN再WG，均可使用已有HTTPS或系统SSH；不改变DSH loopback监听、不放开非本机HTTP。旧单入口记录自动视为一条。节点列表按保存顺序显示，入口可上移/下移，不按最近打开重排。节点仍一个窗口/分区，SSH的本地端口按节点UUID稳定，因此LAN/WG SSH共用同origin；HTTPS不同origin的Cookie/LocalStorage遵循浏览器边界，不拷贝凭据。

桌面“添加本机DSH”快捷按钮保存默认http://127.0.0.1:3080/，已有该入口时不重复，提示已有；初次token由用户一次性输入。按钮不启动Host。Android界面保留原单入口，不构建发布其他平台。

打开时Rust独立校验全部入口和瞬态token，再依序尝试；HTTPS/loopback HTTP无凭据探测最多3秒，系统TLS验证、不跟随重定向、不读取响应正文/不持久Cookie，200/3xx/401/403仅代表可达；404/5xx等失败会尝试下一条。SSH复用现有系统OpenSSH和生命周期监督，首次就绪等待限5秒，进程失败/超时kill+wait再下条。本次打开只把token发送给最终选择的入口。全部失败只给固定安全错误，不显示系统原始错误。最多8条避免无界等待。

已有窗口保持当前入口；点击打开仅聚焦/重新认证，不主动切换；关闭重开或编辑保存关闭旧窗口后按最新顺序选择。SSH运行中继续原有3次恢复，不在活动会话中自动换origin。状态显示“当前入口：LAN/WG”和尝试过程；失败不能称已认证。编辑旧记录不更换UUID/partition，删除行为沿用。

Approaches：分别保存LAN/WG两个节点简单但无法自动回退；并发测速会背离指定优先级并增加同时连接。采用同节点顺序入口/限时尝试，满足用户明确LAN优先需求。先验证macOS不触发Windows/Linux/AndroidCI，不更新.13已装测试版。
