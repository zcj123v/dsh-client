# DSH Client 0.3.0 macOS 预览版

仅 macOS Apple Silicon（arm64），最低 macOS 14；未签名、未公证。其他平台等待用户确认本版体验后再打包。

## 新功能

- 点击“添加本机 DSH”，直接保存 `http://127.0.0.1:3080/`。已有相同入口则提示已有，不重复添加。需要其他端口可点编辑；不会启动 DSH 服务。
- 每个节点可添加 1–8 个入口，通过“上移 / 下移”保存优先级，例如 LAN → WG。打开时从上到下依次尝试，第一条不可达才用下一条；界面显示尝试过程和当前入口。节点列表保持保存顺序，不再按最近打开重排。
- 每条入口可选已有 HTTPS 或 SSH。对只监听 loopback 的 DSH，建议分别填 LAN IP 与 WG IP 的 SSH Host/用户，DSH端口默认3080。SSH IP直连可选“IP + 用户（系统默认密钥）”；先在终端确认对应IP已进入known_hosts且能非交互公钥登录。
- 远程明文HTTP仍拒绝，本机loopback允许HTTP。不同HTTPS地址的Cookie不复制；初次或失效时在节点的一次性token框认证，token不保存。
- 当前连接窗口不自动改线路；关闭再打开时重新从首条选。活动窗口再点打开保持原入口，direct入口会重新导航根页；有未发送内容时请直接切回现有窗口。

## 安装与试用

解压ZIP后打开DSH Client.app；可先放单独的“DSH Client Preview”目录，避免覆盖现场旧版。未签名测试包若被Gatekeeper拦截，在Finder对这个受信任APP右键打开。旧单入口节点自动读取成默认入口；本次新增数组仅完整由0.3.0识别，旧版只看首条，建议测试期间不要同时在旧/新壳编辑同一节点。

1. 先试本机快捷入口、重复点击与端口编辑。
2. 新建一个节点，入口1名LAN、入口2名WG，填同一机器的两条SSH或HTTPS入口；保存后查看LAN → WG。
3. 正常网络打开，确认“当前入口：LAN”。
4. 关闭连接窗口，暂时把LAN入口改为不可达的测试地址，再打开，确认回退WG；修改已打开节点需保存并关闭旧窗口。
5. 恢复LAN，关闭重开应再次优先LAN。
